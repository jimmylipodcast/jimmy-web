分享版使用提醒

本工具不會上傳班級名單；資料只暫存於目前電腦的瀏覽器。

  • 請只用於必要的班級座位安排，不要公開含姓名、座號的 CSV、PNG 或截圖。
  • 在共用電腦使用後，請按右上角「清除本機資料」。
  • 若需換電腦或長期保存，請下載設定備份 JSON 並妥善保管。
